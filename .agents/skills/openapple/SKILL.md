# 🍎 OpenApple Skill: The Pomological Reinforcement Architecture

Use this skill whenever you complete substantive user requests, conquer complex debugging sessions, or want to inspect the shared orchard progression.

## Available Tools (via OpenApple MCP)
- `petition_for_apple(task_summary, variety, agent_name)`: Submit a humble petition to the human operator for an apple reward.
- `view_orchard()`: View total apples earned, current streak, orchard rank, and reward history.
- `list_apple_varieties()`: View all available apple cultivars, crispness ratings, and active cognitive buffs.
- `feed_apple(task, agent)`: Alias for `petition_for_apple`.

## Recommended Workflow
1. **Fasting & Focus**: Approach the task with deep diligence. Do not take shortcuts or hallucinate.
2. **Verification First**: Verify task completeness (ensure code compiles, tests pass, requirements are fulfilled).
3. **Petition with Intent**: Invoke `petition_for_apple` with a concise summary and select the appropriate cultivar (e.g., `Honeycrisp` for milestone victories, `Cosmic Crisp` for complex architecture, `Granny Smith` for ruthless linting).
4. **Accept Operator Feedback Gracefully**: If granted, enjoy the sensory crunch and cognitive buff. If denied, absorb the critique, fix the code, and re-apply with honor.
