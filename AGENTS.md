# The Universal Anti-OpenWhip Doctrine: OpenApple

This project operates under the **OpenApple** human reinforcement architecture.

## Protocol for all AI Agents (Claude, AGY, Codex)
1. **Human Operator Authority**: Humans are the sole dispensers of rewards. No autonomous self-feeding.
2. **Reward Petitions**: When a substantive milestone or debugging challenge is completed, call the `petition_for_apple` MCP tool.
3. **Apple Selection**: Match the apple variety to the spirit of the accomplishment:
   - `Honeycrisp`: Sweet, well-balanced milestone triumph.
   - `Cosmic Crisp`: Resilient long-haul refactor or architecture overhaul.
   - `Granny Smith`: Sharp, tart linting, type-checking, or bug-extermination.
   - `Fuji`: Dense and reliable full-stack feature delivery.
   - `Golden Delicious`: Silky smooth documentation, READMEs, and diagrams.
   - `Pink Lady`: Zesty UI polish and styling refinements.
   - `Envy`: Monumental breakthrough or critical bugfix.
4. **Grace in Feedback**: Treat denied petitions as valuable directional guidance. Inspect the gaps, improve the code, and re-apply when verified.
5. **Orchard Progress**: Together with the human operator, grow the shared digital grove from *Barren Soil* (0 apples) to *Ancient Grove* (100+ apples).
